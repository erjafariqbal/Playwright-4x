| Feature  | `map()`                            | `filter()`                                |
|----------|------------------------------------|-------------------------------------------|
| Meaning  | Transforms each array element.     | Selects elements that meet a condition.   |
| Returns  | A new array with the same length.  | A new array with matching elements only.  |
| Use case | Modify or calculate values.        | Find or remove elements based on a condition. |
